# 📊 Pesquisa de Satisfação - Empresa TudoWeb

Atividade desenvolvida para a **Agenda 08** do Curso Técnico em Desenvolvimento de Sistemas, com foco em Lógica de Programação e Estruturas de Repetição.

## 📝 Sobre o Projeto

Este projeto consiste em um script Python desenvolvido para coletar e tabular dados de uma pesquisa de opinião de atendimento ao cliente para a empresa fictícia TudoWeb. 

O programa recebe os dados de 50 entrevistados e, ao final da execução, gera um relatório apontando quantas pessoas avaliaram o atendimento como "EXCELENTE" e quantas o avaliaram como "RUIM".

## 🚀 Tecnologias Utilizadas

* **Linguagem:** Python 3
* **Conceitos aplicados:**
  * Estruturas de repetição (`for` e `while`)
  * Estruturas de decisão (`if` / `elif`)
  * Validação de entrada de dados (tratamento de erros básicos)
  * Variáveis contadoras

## ⚙️ Funcionalidades

* Solicita o **Nome** e a **Idade** do entrevistado.
* Solicita a **Opinião** baseada no seguinte menu:
  * `1` - EXCELENTE
  * `2` - BOM
  * `3` - RUIM
* **Validação:** Impede que o usuário digite valores fora do intervalo (1 a 3), exigindo a digitação correta para prosseguir.
* **Relatório:** Ao final da coleta, exibe na tela o total de avaliações EXCELENTES e RUINS.

## 🧪 Testes e Validação

De acordo com as orientações da atividade, o código final está configurado para **50 entrevistados**. 

No entanto, os testes de validação lógica (comprovação de funcionamento) foram realizados simulando **10 entrevistados**. As capturas de tela (*prints*) demonstrando a execução bem-sucedida do código no terminal (coleta e relatório final) encontram-se anexadas neste repositório.
